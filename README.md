# 🧠 ToDo App Full Stack – Java + React

Bem-vindo ao **ToDo App**, uma aplicação full stack moderna, construída com **Java (Spring Boot)** no back-end e **Next.js com React** no front-end. O projeto foi desenvolvido com foco em boas práticas, responsividade e fluidez visual, incluindo animações suaves e código limpo.

---

## 🚀 Tecnologias Utilizadas

| Camada     | Tecnologias                 |
|------------|-----------------------------|
| Frontend   | React, Next.js, TailwindCSS, Axios |
| Backend    | Java, Spring Boot, PostgreSQL |
| Infraestrutura | REST API, Gradle/Maven, GitHub |

## 🛠 Como Executar

### 1. Clonar o projeto

```bash
git clone https://github.com/micarique/todolist.git
cd todolist
```

### 2. Iniciar o back-end

```bash
cd todolist-backend
./mvnw spring-boot:run
```

> Certifique-se de ter o PostgreSQL rodando e a tabela `tasks` criada.

### 3. Iniciar o front-end

```bash
cd todolist-frontend
npm install
npm run dev
```
